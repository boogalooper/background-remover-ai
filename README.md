# Background Remover AI

Background Remover AI — программа для пакетного удаления фона с фотографий.

Она работает **локально на компьютере**: фотографии никуда не отправляются.

**Исходные файлы не изменяются и не перезаписываются.** Готовые изображения и маски всегда сохраняются отдельно.

---

# Что умеет программа

Background Remover AI может:

- обработать один файл, несколько файлов или целую папку;
- искать фотографии во вложенных папках;
- сохранять структуру подпапок;
- удалять фон с помощью нескольких AI-моделей для разных задач;
- подсказывать, для каких фотографий лучше подходит выбранная модель;
- заранее скачать все доступные модели одной кнопкой;
- сохранять изображение с прозрачностью в PNG или TIFF;
- сохранять отдельную чёрно-белую маску;
- сохранять одновременно прозрачное изображение и маску;
- немного расширять или сжимать край маски;
- дополнительно очищать цветную кайму на полупрозрачном краю объекта;
- сохранять пропорции изображения при работе с BiRefNet Dynamic;
- работать на NVIDIA GPU;
- останавливаться по кнопке **«Отмена»**;
- запускаться из Total Commander;
- запоминать основные настройки между запусками.

Поддерживаемые входные форматы:

```text
JPG / JPEG / PNG / TIF / TIFF / WebP / BMP / PSD / PSB
```

RAW-файлы камер (`CR2`, `CR3`, `NEF`, `ARW` и т. п.) напрямую не обрабатываются. Для них сначала подготовьте JPEG или TIFF.

# Быстрый старт

## 1. Установка

1. Распакуйте программу в отдельную папку.
2. Запустите `install.bat`.
3. Для обычной установки выберите:

```text
1 — Normal secure mode
```

4. Дождитесь сообщения об успешном завершении.
5. Запускайте программу через:

```text
run.bat
```

При первой установке нужен интернет.

**Системный Python устанавливать не требуется.** Всё необходимое программа устанавливает самостоятельно в свою папку.

Если установка прерывается из-за проверки HTTPS-сертификата антивирусом, повторите её и выберите режим совместимости:

```text
2 — Compatibility mode
```

Используйте его только если обычный вариант не работает.

---

# Первый запуск

На вкладке **«Быстрый старт»**:

1. выберите фотографии или папку;
2. проверьте папку результата;
3. выберите модель;
4. выберите, что сохранить;
5. оставьте профиль края **«Рекомендуемый для выбранной модели»**;
6. нажмите **«НАЧАТЬ ОБРАБОТКУ»**.

Под списком моделей показывается короткая подсказка с назначением, главным преимуществом и ограничениями выбранной модели. Полное описание, включая лицензию и дополнительные детали, доступно при наведении на эту подсказку.

Для первого теста лучше выбрать **5–20 типичных фотографий**, а не сразу всю съёмку.

Полезно проверить разные случаи:

- распущенные волосы;
- светлую одежду на светлом фоне;
- тёмную одежду на тёмном фоне;
- руки и пальцы;
- мелкие аксессуары;
- погрудный портрет;
- ростовой портрет.

# Рекомендуемые настройки для начала

Для большинства задач попробуйте:

```text
Модель:                       BRIA RMBG-2.0 или BiRefNet Standard
Выход:                        Прозрачный файл + маска
Формат:                       PNG
Край:                         Рекомендуемый для выбранной модели
Очистка цвета края:           включена
Сохранять структуру папок:    включено
Перезаписывать готовые файлы: выключено
Безопасное ограничение GPU:   включено
FP16 на NVIDIA:               включено
```

Сначала оцените результат без ручной настройки параметров маски.

Если качество устраивает — ничего дополнительно менять не нужно.

# Вкладки программы

Основное окно разделено на три вкладки:

- **«Быстрый старт»** — выбор фотографий, папки результата, модели и основных параметров запуска;
- **«Маска и край»** — все параметры, которые непосредственно меняют маску, границу объекта и цвет полупрозрачного края;
- **«Общие настройки»** — предварительное скачивание моделей, BRIA, производительность, память и параметры сохранения файлов.

Если нужно только обработать фотографии с обычными настройками, достаточно вкладки **«Быстрый старт»**.

Для тонкой настройки качества края используйте вкладку **«Маска и край»**.

# Выбор модели

В программе есть несколько моделей. Они отличаются скоростью, расходом видеопамяти и тем, на каких объектах дают лучший край.

При выборе модели прямо в окне программы показываются:

- для каких фотографий она подходит лучше всего;
- её основные ограничения;
- примерная скорость;
- характер края;
- рекомендуемый безопасный размер GPU-пакета.

Не существует одной модели, которая всегда лучше остальных. Для важных съёмок полезно один раз сравнить 2–3 подходящих варианта на своих фотографиях.

## BRIA RMBG-2.0 — универсальная

Хороший первый вариант для:

- людей;
- предметов;
- обычных фотографий;
- школьной и студийной съёмки.

Это универсальная модель с хорошим балансом между качеством и скоростью.

Для BRIA требуется доступ к модели на Hugging Face.

Если в глобальных переменных окружения Windows уже задан:

```text
HF_TOKEN
```

программа обнаружит его и использует автоматически. Сам токен в интерфейсе и журнале не показывается.

Если `HF_TOKEN` не задан, после установки можно использовать:

```text
setup_bria.bat
```

и следовать подсказкам на экране.

Перед первым использованием BRIA также необходимо принять условия доступа к модели на Hugging Face.

---

## BiRefNet Standard — универсальная

Хороший вариант для:

- людей;
- предметов;
- повседневной пакетной обработки;
- случаев, когда не хочется сразу использовать тяжёлую HR-модель.

Это базовая универсальная BiRefNet с хорошим балансом качества, скорости и расхода видеопамяти.

Если вы не знаете, с какой BiRefNet начать, попробуйте сначала именно её.

---

## BiRefNet Lite — быстрый

Подходит для:

- больших папок;
- предварительной обработки;
- менее мощных видеокарт;
- задач, где скорость важнее максимальной детализации края.

Lite обычно быстрее остальных вариантов BiRefNet и позволяет использовать более крупный GPU-пакет.

На сложных волосах, мехе и мелких деталях качество может быть ниже, чем у Standard, HR или Matting.

---

## BiRefNet Portrait — люди

Вариант, ориентированный на людей.

Особенно полезен для:

- портретов;
- погрудных фотографий;
- ростовых фотографий;
- кадров, где главным объектом является человек.

Для предметов и сложных объектов универсальные варианты иногда работают лучше.

---

## BiRefNet Matting — мягкий край

Попробуйте эту модель, если особенно важны:

- волосы;
- мех;
- фата;
- тонкие ткани;
- полупрозрачные детали;
- мягкий переход между объектом и фоном.

Она рассчитана именно на более сложный matting-край.

Для обычных предметов и простых контуров может быть избыточной.

---

## BiRefNet HR — высокое разрешение

Модель для больших изображений и мелких деталей.

Полезна для:

- крупных исходников;
- детализированных предметов;
- сложного контура;
- случаев, когда разрешения обычной 1024 px модели уже недостаточно.

Она требует больше видеопамяти и работает медленнее стандартных вариантов.

---

## BiRefNet HR Matting — максимум деталей

Самый тяжёлый вариант для сложного мягкого края.

Попробуйте его для:

- распущенных волос;
- меха;
- фаты;
- размытого края;
- мелких деталей на больших 20–60 Мп фотографиях.

Модель работает в 2048 px и обычно требует GPU-пакет `1`.

Для простых фотографий использовать её постоянно необязательно — более лёгкая модель может дать практически такой же результат заметно быстрее.

---

## BiRefNet Dynamic — разные пропорции

Этот вариант отличается от остальных тем, что при подготовке изображения **сохраняет его пропорции**, а не приводит любой кадр к квадратному входу.

Полезен для:

- вертикальных фотографий;
- панорам;
- очень широких или вытянутых кадров;
- смешанных папок с разными форматами изображений.

Модель использует динамический размер входа и может расходовать больше видеопамяти.

Главное её преимущество — не максимальная скорость, а более естественная обработка фотографий с сильно отличающимися пропорциями.

---

# Как сравнивать модели

Для теста удобно выбрать:

```text
Выход → Прозрачный файл + маска
```

Тогда для каждого исходника будут созданы, например:

```text
IMG_0001_cutout.png
IMG_0001_mask.png
```

По отдельной маске проще заметить:

- потерянные волосы;
- остатки фона;
- пропавшие пальцы или аксессуары;
- слишком жёсткий или слишком мягкий край.

---

# Что сохранять

В программе есть три основных варианта.

## Прозрачный файл

Создаётся готовое изображение без фона.

Например:

```text
IMG_0001.jpg
↓
IMG_0001_cutout.png
```

Можно выбрать PNG или TIFF.

---

## Только маска

Создаётся отдельный PNG:

```text
IMG_0001_mask.png
```

В маске:

- белое — объект;
- чёрное — фон;
- серое — частичная прозрачность.

Этот вариант удобен для последующей ручной работы в Photoshop.

---

## Прозрачный файл + маска

Создаются оба файла.

Это лучший вариант для первых тестов и сравнения качества.

---

# PNG или TIFF

## PNG

Для большинства задач рекомендуется PNG.

Плюсы:

- поддерживает прозрачность;
- хорошо открывается в Photoshop и других программах;
- обычно занимает меньше места;
- удобен для пакетной обработки.

---

## TIFF

Используйте TIFF, если ваш дальнейший рабочий процесс построен вокруг TIFF/Photoshop.

TIFF обычно занимает больше места, но также сохраняет прозрачность.

Если вам не нужен именно TIFF, проще начать с PNG.

---

# PSD и PSB

PSD и PSB можно передавать программе так же, как JPEG или TIFF.

Программа использует **видимое итоговое изображение документа**, а не отдельный слой.

Исходный PSD/PSB не изменяется.

Если документ очень большой и содержит много слоёв, для его открытия может потребоваться заметно больше оперативной памяти.

Для наиболее предсказуемого результата желательно сохранять PSD/PSB в Photoshop с включённой совместимостью файла.

---

# Папка результата

По умолчанию программа предлагает подпапку:

```text
Background Removed
```

Например:

```text
D:\Photos\1A\IMG_001.jpg
```

может дать:

```text
D:\Photos\1A\Background Removed\IMG_001_cutout.png
```

---

# Сохранение структуры подпапок

Если исходная съёмка разложена так:

```text
Shoot\
├─ 1A\IMG_001.jpg
├─ 1B\IMG_100.jpg
└─ 2A\IMG_200.jpg
```

при включённом сохранении структуры результат будет выглядеть примерно так:

```text
Background Removed\
├─ 1A\IMG_001_cutout.png
├─ 1B\IMG_100_cutout.png
└─ 2A\IMG_200_cutout.png
```

Это удобно для больших съёмок, уже разложенных по классам, заказам или другим папкам.

---

# Повторный запуск на тех же фотографиях

По умолчанию:

```text
Перезаписывать готовые файлы = выключено
```

Это безопасный режим.

Если результат уже существует, программа его не заменяет.

Например, если уже есть:

```text
IMG_0001_cutout.png
```

но нет:

```text
IMG_0001_mask.png
```

в режиме «Прозрачный файл + маска» программа может создать только недостающую маску.

## Важно при изменении настроек

Если вы изменили край, пороги, гамму или другие параметры, но перезапись выключена, старый файл останется прежним.

Чтобы сравнить новые настройки на тех же фотографиях:

- включите **«Перезаписывать готовые файлы»**;
- или выберите другую папку результата.

# Настройка края

На первом экране есть готовые профили. Тот же список доступен на вкладке **«Маска и край»**.

## Рекомендуемый для выбранной модели

Основной вариант для обычной работы.

Он применяет полный набор параметров маски и края, рекомендованный именно для текущей модели:

- нижний и верхний пороги маски;
- гамму;
- расширение или сжатие края;
- размытие края;
- Guided Refine и его параметры;
- очистку цветной каймы и её силу.

Если затем выбрать другую модель во вкладке **«Быстрый старт»**, пока этот профиль остаётся выбранным, программа автоматически установит рекомендации уже для новой модели.

Если изменить любой из этих параметров вручную, профиль автоматически станет **«Пользовательский»**.

## Пользовательские пресеты

На вкладке **«Маска и край»** можно сохранить текущие параметры как собственный именованный пресет.

Нажмите **«Создать пресет из текущих»**, задайте название — после этого пресет появится в списке **«Профиль края»** и в «Быстром старте» с пометкой **«Мой пресет: ...»**.

Пользовательский пресет сохраняет весь набор параметров этой вкладки:

- нижний и верхний пороги маски;
- гамму;
- сдвиг и размытие края;
- Guided Refine и его параметры;
- очистку цветной каймы и её силу.

Пресеты сохраняются между запусками программы в `config/custom_mask_presets.json`.

Чтобы удалить сохранённый пресет, выберите его и нажмите **«Удалить пресет»**. Кнопка удаления активна только для собственных сохранённых пресетов.

Встроенные профили **«Рекомендуемый для выбранной модели»**, **«Естественный край»**, **«Чище фон»** и **«Без дополнительной обработки»** удалить нельзя.

Состояние **«Пользовательский»** означает, что текущие параметры вручную отличаются от известных профилей, но ещё не сохранены как отдельный пресет.

---

## Естественный край

Нейтральный модель-независимый профиль. Он не подстраивается автоматически при смене модели.

Подходит как спокойная отправная точка для ручной настройки и сравнения моделей.

---

## Чище фон

Сильнее убирает слабые остатки фона.

Может быть полезен на простом ровном фоне, но иногда слишком сильно съедает:

- тонкие волосы;
- прозрачную ткань;
- мелкие детали.

---

## Без дополнительной обработки

Оставляет маску модели почти без дополнительной коррекции и отключает очистку цвета полупрозрачного края.

Полезно для:

- сравнения моделей;
- диагностики;
- дальнейшей ручной обработки.

---

# Сдвиг края маски

В расширенных настройках можно немного расширить или сжать объект.

```text
+ значение  → расширить объект
- значение  → сжать объект
0           → не менять край
```

На очень больших фотографиях изменение в несколько пикселей может быть почти незаметно.

Если хотите проверить, работает ли параметр, временно попробуйте заметное значение:

```text
+30
```

а затем:

```text
-30
```

После этого вернитесь к более аккуратному значению.

Не забудьте разрешить перезапись готового результата.

---

# Размытие края

Дополнительное размытие обычно лучше оставлять на:

```text
0
```

Современные модели уже создают мягкий переход там, где это нужно.

Слишком большое размытие может дать заметный ореол вокруг объекта.

---

# Экспериментальное уточнение края

Опция:

**«Экспериментально уточнять край по исходному изображению»**

может дополнительно улучшить границу маски.

По умолчанию она выключена.

Используйте её только если обычный результат систематически выглядит слишком грубо.

На некоторых фотографиях она может, наоборот, сильнее захватить детали фона, поэтому сравнивайте результат на нескольких кадрах.

---

# Очистка цвета полупрозрачного края

Опция:

**«Очищать цвет полупрозрачного края в прозрачном файле»**

уменьшает цветную кайму вокруг объекта.

Например, если волосы сняты на синем фоне, часть полупрозрачных пикселей по краю может сохранить синий оттенок. После помещения такого PNG на белый фон появляется заметный ореол.

Очистка края пытается уменьшить такой цветовой остаток.

Она полезна для:

- волос;
- меха;
- фаты;
- размытого края одежды;
- фотографий на ярком цветном фоне.

По умолчанию её можно оставить включённой.

Параметр **«Сила очистки цвета края»** обычно лучше держать примерно в диапазоне:

```text
0.45–0.65
```

Слишком большое значение на необычных полупрозрачных объектах может изменить естественный цвет края.

Эта настройка относится только к PNG/TIFF с прозрачностью. Если выбран режим **«Только чёрно-белая маска»**, соответствующие элементы интерфейса блокируются, потому что на саму маску очистка цвета не влияет.

---

# Настройки, зависящие от модели и режима

Интерфейс автоматически блокирует параметры, которые в текущий момент не используются.

Например:

- параметры экспериментального уточнения края блокируются, пока само уточнение выключено;
- очистка цветной каймы блокируется, если сохраняется только маска;
- кнопка настройки BRIA активна только при выборе BRIA;
- для каждой модели показывается её рекомендуемый безопасный GPU-пакет.

Это сделано специально, чтобы не создавать впечатление, что неактуальная настройка влияет на результат.

Отдельной кнопки установки рекомендаций больше нет. Вместо неё используется профиль:

**«Рекомендуемый для выбранной модели»**

Он меняет только параметры маски и края и **не меняет** выбранный формат, режим выхода, структуру папок, перезапись файлов, метаданные, устройство CPU/GPU, FP16, размер GPU-пакета, потоки чтения, буфер предзагрузки и другие общие настройки.

Пока этот профиль выбран, смена модели автоматически обновляет относящиеся к качеству параметры под новую модель. Ручное изменение любого такого параметра переводит профиль в состояние **«Пользовательский»**.

# Производительность

Если скорость устраивает, оставьте настройки по умолчанию.

## NVIDIA GPU

На компьютере с NVIDIA обычно рекомендуется:

```text
Устройство:                 auto
FP16:                       включено
Безопасно ограничивать GPU: включено
```

В режиме `auto` программа сама пытается использовать видеокарту.

Если в журнале указано `cpu`, хотя NVIDIA есть, смотрите раздел устранения проблем ниже.

---

## Кадров за один GPU-проход

Этот параметр определяет, сколько фотографий программа пытается обработать за один проход.

Большее значение иногда ускоряет работу, но требует больше видеопамяти.

Если появляются ошибки нехватки VRAM, поставьте:

```text
1
```

---

## Потоки чтения файлов

Пока видеокарта обрабатывает текущую фотографию, программа может заранее читать следующие.

Хорошая отправная точка:

```text
2
```

На быстром SSD можно попробовать:

```text
3–4
```

---

## Буфер предзагрузки

Определяет, сколько следующих изображений может заранее находиться в оперативной памяти.

Для больших файлов обычно достаточно:

```text
3
```

Больший буфер не обязательно делает программу быстрее.

- текущий этап;
- имя файла;
- общий процент;
- количество обработанных;
- количество пропущенных;
- количество ошибок.

Уже полностью сохранённые результаты остаются на месте.

# Безопасность исходных файлов

Программа **не изменяет исходные фотографии**.

Она не заменяет исходный JPEG/TIFF прозрачной версией и не записывает маску обратно в оригинал.

Результат всегда создаётся отдельно.

Если исходный PNG или TIFF уже содержит прозрачность, существующая прозрачность сохраняется.

```text
F:\background_remover_ai\run.bat
```

**Параметры:**

# Какие настройки запоминаются

Программа сохраняет большинство рабочих настроек между запусками, в том числе:

- модель;
- PNG/TIFF;
- режим результата;
- профиль края;
- пользовательские пресеты маски;
- параметры маски;
- очистку цвета полупрозрачного края;
- работу с подпапками;
- перезапись;
- настройки CPU/GPU;
- размер GPU-пакета;
- потоки чтения.

Список выбранных фотографий как постоянное задание не сохраняется.

Профиль **«Рекомендуемый для выбранной модели»** возвращает только параметры маски и края к рекомендуемой отправной точке для выбранной модели. Общие настройки программы он не изменяет.

# Первый запуск новой модели

Веса моделей не входят в небольшой архив программы.

При первом использовании выбранная модель скачивается автоматически.

Поэтому первый запуск новой модели может занять заметно больше времени.

После загрузки модель сохраняется локально в папке программы, и следующие запуски обычно проходят быстрее. Это не означает, что старая модель остаётся постоянно загруженной в видеопамяти: при каждом запуске обработки выбранная модель создаётся заново из локального кэша, а после завершения обработки backend освобождается и CUDA-кэш очищается.

Во время обработки список моделей во вкладке **«Быстрый старт»** блокируется, поэтому видимая модель не может разойтись с той, которая фактически была запущена. В постоянном блоке **«Ход работы»** отдельно показывается состояние модели: загрузка, активная модель и её выгрузка после завершения.

Если все выходные файлы уже существуют и выключена перезапись, модель вообще не загружается. В этом случае программа прямо пишет **«Модель не запускалась»**.

---

# Скачать все модели заранее

Если компьютер будет использоваться без постоянного доступа к интернету или вы хотите заранее подготовить все модели, откройте вкладку **«Общие настройки»** и используйте кнопку. Выбор рабочей модели остаётся только во вкладке **«Быстрый старт»**:

**«Скачать все модели»**

Программа последовательно загрузит доступные модели в локальный Hugging Face-кэш внутри папки Background Remover AI.

Уже скачанные файлы используются из кэша и повторно не загружаются без необходимости. Поэтому повторное нажатие кнопки в первую очередь **проверяет и при необходимости дозагружает** модели, а не скачивает весь объём заново.

Для временных сетевых ошибок программа автоматически повторяет попытку загрузки модели до трёх раз. Модель считается неготовой только если повторные попытки не помогли. Ошибки доступа к закрытой модели, например BRIA без принятой лицензии, повторно не запрашиваются бессмысленно.

Во время предварительного скачивания модели **не загружаются в GPU и не выполняют обработку изображений** — скачиваются только необходимые файлы.

Если для BRIA нет доступа, это не должно мешать скачиванию остальных моделей. В конце программа сообщит, какая модель осталась неготовой.

Если задан глобальный `HF_TOKEN`, он будет использован автоматически.

Предварительно скачивать все модели необязательно. Если вы используете только одну-две модели, проще позволить программе загрузить их при первом запуске.

# Если что-то пошло не так

## Программа работает на CPU вместо NVIDIA

Если в журнале указано:

```text
устройство: cpu
```

хотя в компьютере есть NVIDIA, снова запустите:

```text
install.bat
```

После установки повторите тест.

---

## BRIA не запускается

Сначала убедитесь, что на странице модели BRIA в Hugging Face приняты условия доступа.

Если в Windows уже задана глобальная переменная:

```text
HF_TOKEN
```

программа должна использовать её автоматически.

Если `HF_TOKEN` не задан, запустите:

```text
setup_bria.bat
```

и проверьте, что настройка доступа к модели завершена успешно.

Само наличие токена не заменяет принятие условий доступа к закрытой модели.

---

## На волосах остаётся фон

Попробуйте по порядку:

1. профиль **«Рекомендуемый для выбранной модели»**;
2. **BiRefNet Matting**;
3. **BiRefNet HR Matting** для большого исходника или особенно сложного края;
4. очистку цвета полупрозрачного края, если проблема именно в цветной кайме;
5. экспериментальное уточнение края;
6. только затем ручную настройку маски.

Не начинайте сразу с сильного сжатия маски — вместе с фоном можно потерять волосы.

---

## Волосы или прозрачная ткань пропадают

Вернитесь к:

```text
Естественный край
```

или:

```text
Без дополнительной обработки
```

Если проблема остаётся, сравните другую модель.

---

## Изменение края не видно

Проверьте:

1. включена ли перезапись готовых файлов;
2. достаточно ли велик тестовый сдвиг.

Для проверки попробуйте сначала:

```text
+30
```

и:

```text
-30
```

После этого подберите более аккуратное значение.

---

## Не хватает видеопамяти

Попробуйте:

1. оставить безопасное ограничение GPU включённым;
2. поставить **«Кадров за один GPU-проход» = 1**;
3. закрыть другие программы, активно использующие видеокарту.

---

## TIFF не сохраняется

Попробуйте тот же кадр сохранить как PNG.

Если PNG сохраняется, а TIFF нет, сохраните журналы:

```text
background_remover_ai.log
background_remover_ai_crash.log
```

и приложите их к сообщению об ошибке.

---

## Программа ничего не обрабатывает после изменения настроек

Скорее всего, результаты уже существуют, а перезапись выключена.

Чтобы применить новые параметры:

- включите перезапись;
- или выберите новую папку результата.

---

## Первый запуск долго стоит на «Загрузка модели»

Это нормально, если модель используется впервые.

Она может скачиваться в этот момент.

После первой загрузки следующие запуски обычно проходят быстрее.

# Перенос программы

Папку Background Remover AI можно переименовать или перенести на другой локальный диск.

Системный Python для запуска не требуется.

После переноса используйте обычный:

```text
run.bat
```

Если программа сообщает, что локальное окружение отсутствует или повреждено, один раз запустите:

```text
install.bat
```

Скачанные модели хранятся внутри папки программы и обычно переносятся вместе с ней.

# Рекомендуемые настройки для первого знакомства

## Обычный портрет / школьная фотография

```text
Модель:                       BRIA RMBG-2.0
Выход:                        Прозрачный файл + маска
Формат:                       PNG
Край:                         Рекомендуемый для выбранной модели
Очистка цвета края:           включена
Перезапись:                   выключена
Уточнение края:               выключено
Устройство:                   auto
FP16:                         включено
Безопасный GPU-пакет:         включён
Потоки чтения:                2
Буфер предзагрузки:           3
```

Если BRIA ещё не настроена, начните с:

```text
BiRefNet Standard
```

## Если особенно важны волосы и сложный край

```text
Модель:                       BiRefNet Matting или BiRefNet HR Matting
Выход:                        Прозрачный файл + маска
Край:                         Рекомендуемый для выбранной модели
Очистка цвета края:           включена
GPU-пакет для HR Matting:     1
Уточнение края:               сначала выключено
```

Сначала оцените результат самой модели. Дополнительные настройки включайте только если видите конкретную проблему.

## Если фотографии очень разные по пропорциям

Попробуйте:

```text
BiRefNet Dynamic
```

Она сохраняет пропорции изображения при подготовке кадра для модели и особенно полезна для смешанных папок с вертикальными, горизонтальными и сильно вытянутыми фотографиями.

# Главное

Для большинства задач рабочий процесс очень простой:

1. выбрать фотографии или папку;
2. выбрать модель;
3. оставить **«Рекомендуемый для выбранной модели»**;
4. выбрать PNG и при необходимости маску;
5. запустить обработку;
6. проверить несколько результатов;
7. только при необходимости менять дополнительные параметры.

Исходные фотографии при этом остаются без изменений.
