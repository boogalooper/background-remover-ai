# Background Remover AI v0.1.6 — пакетное удаление фона

Background Remover AI — локальная Windows-программа для **пакетного удаления фона с фотографий**.

Программа рассчитана прежде всего на обычный фотографический рабочий процесс: выбрать папку или несколько файлов, выбрать модель, получить прозрачные изображения и при необходимости отдельные маски.

**Исходные фотографии не изменяются и не перезаписываются.** Результат всегда сохраняется отдельно.

Все фотографии обрабатываются **локально на вашем компьютере**. После того как модель скачана, сами фотографии никуда не отправляются.

---

## Что умеет программа

Программа может:

- обрабатывать **один файл, несколько выбранных файлов или целую папку**;
- при необходимости проходить вложенные папки;
- автоматически сохранять структуру подпапок;
- удалять фон с помощью нескольких моделей;
- сохранять готовый файл с прозрачностью в **PNG** или **TIFF**;
- сохранять отдельную чёрно-белую маску;
- сохранять одновременно прозрачный файл и маску;
- аккуратно расширять или сжимать край маски;
- выполнять пакетную обработку на NVIDIA GPU;
- заранее читать следующие файлы в несколько CPU-потоков;
- останавливаться по кнопке **«Отмена»**;
- запускаться напрямую из **Total Commander** с `%P%S`;
- запоминать пользовательские настройки между запусками.

Поддерживаемые входные форматы:

`JPG / JPEG / PNG / TIF / TIFF / WebP / BMP`

RAW-файлы камеры (`CR2`, `CR3`, `NEF`, `ARW` и т. п.) текущая версия напрямую не проявляет. Для них сначала нужен JPEG или TIFF.

# Быстрый старт

## 1. Установка

1. Распакуйте архив программы в отдельную папку, например:

   ```text
   D:\Programs\Background Remover AI
   ```

2. Запустите:

   ```text
   install.bat
   ```

3. Для обычной установки выберите:

   ```text
   1 — Normal secure mode
   ```

4. Дождитесь окончания установки.

5. После этого запускайте программу через:

   ```text
   run.bat
   ```

Программа создаёт собственное локальное Python-окружение в:

```text
runtime\venv
```

Системный Python и другие ваши программы не изменяются.

Если Python 3.11 x64 отсутствует, установщик попробует найти или установить его автоматически.

Если на компьютере есть поддерживаемая NVIDIA, установщик проверяет CUDA и ставит подходящую GPU-сборку PyTorch. Запуск установщика из **32-битного Total Commander поддерживается**.

### Если обычная установка не проходит из-за антивируса

Если Kaspersky или другое ПО перехватывает HTTPS и появляются ошибки сертификатов, запустите `install.bat` ещё раз и выберите:

```text
2 — Compatibility mode for HTTPS interception
```

Используйте этот режим только если обычный вариант не сработал.

---

## 2. Первый запуск

На вкладке **«Быстрый старт»**:

1. выберите папку или фотографии;
2. проверьте папку результата;
3. выберите модель;
4. выберите, что сохранить;
5. оставьте профиль края **«Естественный край»**;
6. нажмите **«НАЧАТЬ ОБРАБОТКУ»**.

Для первого знакомства лучше взять **5–20 типичных фотографий**, а не сразу всю съёмку.

Особенно полезно проверить:

- распущенные волосы;
- светлую одежду на светлом фоне;
- тёмную одежду на тёмном фоне;
- руки и пальцы по краю фигуры;
- мелкие аксессуары;
- погрудный портрет;
- ростовой портрет.

# Рекомендуемый рабочий процесс

Для большинства задач начните так:

```text
Модель:                         BRIA RMBG-2.0 или BiRefNet HR Matting
Выход:                          Прозрачный файл + маска
Формат прозрачного файла:       PNG
Край:                           Естественный край
Включать подпапки:              по необходимости
Сохранять структуру подпапок:   включено
Перезаписывать готовые файлы:   выключено
Безопасно ограничивать GPU:     включено
FP16 на NVIDIA:                 включено
```

Сначала сравните результат **без ручного изменения расширенных параметров**.

Если качество устраивает — на этом настройку можно закончить.

# Выбор модели

В программе есть три варианта.

## BRIA RMBG-2.0 — универсальная

Хороший первый вариант для:

- людей;
- предметов;
- смешанных сцен;
- обычной школьной или студийной фотографии.

Рабочий размер модели — около 1024 px.

Для BRIA требуется один раз настроить доступ через Hugging Face.

После обычного `install.bat` запустите:

```text
setup_bria.bat
```

Далее:

1. войдите в Hugging Face;
2. примите условия модели RMBG-2.0;
3. создайте Read token;
4. вставьте токен в окно настройки.

Модель будет скачана в локальный кэш программы.

BRIA используется здесь для личной / некоммерческой работы.

---

## BiRefNet HR Matting — максимум деталей

Более тяжёлая модель с рабочим размером около **2048 px**.

Имеет смысл попробовать её, если особенно важны:

- волосы;
- мех;
- сложный край одежды;
- тонкие детали;
- сложный контур на неоднородном фоне.

Она обычно медленнее, чем BRIA, но может дать более аккуратную исходную маску.

Аккаунт Hugging Face для неё не требуется.

---

## BiRefNet Portrait — люди

Вариант, ориентированный на людей и портреты.

Он не обязательно всегда лучше универсальной модели — результат сильно зависит от:

- фона;
- света;
- одежды;
- масштаба человека;
- причёски.

Поэтому лучше один раз сравнить несколько моделей на своих реальных фотографиях и выбрать ту, которая лучше подходит именно под вашу съёмку.

---

## Как сравнивать модели

Для сравнения удобно выбрать:

```text
Выход → Прозрачный файл + маска
```

Тогда рядом будут:

```text
IMG_0001_cutout.png
IMG_0001_mask.png
```

По маске проще увидеть:

- потерялись ли волосы;
- остался ли фон;
- пропали ли пальцы или аксессуары;
- насколько плавно выглядит полупрозрачный край.

---

# Что сохранять

В поле **«Выход»** есть три режима.

## PNG/TIFF с прозрачностью

Создаётся готовое изображение без фона.

Например:

```text
IMG_0001.jpg
    ↓
IMG_0001_cutout.png
```

или:

```text
IMG_0001_cutout.tif
```

---

## Только чёрно-белая маска

Создаётся отдельный PNG:

```text
IMG_0001_mask.png
```

В нём:

- белое — объект;
- чёрное — фон;
- серое — частичная прозрачность.

Этот вариант удобен для ручной работы в Photoshop.

---

## Прозрачный файл + маска

Создаются оба файла.

Это лучший режим для первых тестов и настройки качества.

---

# PNG или TIFF

## PNG

Для большинства задач это рекомендуемый вариант.

Плюсы:

- сохраняет прозрачность;
- хорошо поддерживается программами обработки;
- обычно меньше по размеру;
- безопасен и прост для пакетной работы.

---

## TIFF с альфа-каналом

Используйте TIFF, если дальнейший процесс построен вокруг Photoshop / TIFF и размер файла не критичен.

Текущая версия сохраняет прозрачный TIFF как **RGBA TIFF**.

Для устойчивости TIFF записывается безопасным отдельным механизмом и проверяется до того, как временный файл становится итоговым.

Основной вариант сжатия — **Deflate/ZIP**. Если сжатая запись не проходит, программа может повторить сохранение без сжатия вместо того, чтобы потерять результат.

### Метаданные TIFF

Программа старается сохранять:

- ICC-профиль;
- DPI;
- безопасные базовые поля EXIF.

Служебные указатели и внутренние структуры EXIF исходного файла намеренно не копируются в новый TIFF, потому что они относятся к старому контейнеру и могут повреждать производный файл.

# Папка результата

Обычно результат сохраняется в подпапку:

```text
Background Removed
```

Например:

```text
D:\Photos\1A\IMG_001.jpg
```

может дать:

```text
D:\Photos\1A\Background Removed\IMG_001_cutout.png
```

---

## Сохранять структуру подпапок

Если исходная папка выглядит так:

```text
Shoot\1A\IMG_001.jpg
Shoot\1B\IMG_100.jpg
Shoot\2A\IMG_200.jpg
```

при включённой опции структура сохраняется:

```text
Background Removed\1A\IMG_001_cutout.png
Background Removed\1B\IMG_100_cutout.png
Background Removed\2A\IMG_200_cutout.png
```

Это удобно для больших съёмок, уже разложенных по классам, заказам или папкам.

---

# Повторный запуск на тех же фотографиях

По умолчанию:

```text
Перезаписывать готовые файлы = выключено
```

Это безопасный режим.

Если файл уже существует, программа его не заменяет.

В режиме **«Прозрачный файл + маска»** результаты проверяются независимо. Например:

```text
IMG_0001_cutout.png  — уже существует
IMG_0001_mask.png    — отсутствует
```

Программа создаст только маску и не будет перезаписывать готовый cutout.

### Важно при настройке края

Если вы изменили:

- сдвиг края;
- пороги маски;
- гамму;
- размытие;
- guided refinement;

но **«Перезаписывать готовые файлы» выключено**, старый результат останется без изменений.

В таком случае программа прямо сообщает, что новые параметры к существующим файлам не применялись.

Для сравнения настроек на одних и тех же кадрах включите:

```text
Перезаписывать готовые файлы
```

или выберите новую папку результата.

# Настройка края

На первом экране есть три готовых профиля.

## Естественный край — рекомендуется

Основной вариант.

Почти не вмешивается в маску модели и обычно лучше всего сохраняет волосы и полупрозрачные детали.

Начинайте именно с него.

---

## Чище фон

Сильнее убирает слабые полупрозрачные остатки фона.

Может быть полезен на ровном фоне, но иногда слишком агрессивен для:

- тонких волос;
- вуалей;
- прозрачной ткани;
- мелких деталей.

---

## Без дополнительной обработки

Сохраняет маску модели почти как есть.

Хороший вариант для:

- сравнения моделей;
- диагностики;
- дальнейшей ручной доработки.

---

# Расширенные настройки маски

Для обычной обработки раздел **«Расширенные»** можно вообще не открывать.

Открывайте его, когда видите конкретную проблему.

## Удалять слабый фон ниже

Повышение значения сильнее убирает слабые остатки фона.

Слишком большое значение может начать съедать тонкие детали объекта.

---

## Считать объектом выше

Влияет на то, насколько быстро уверенная часть маски становится полностью непрозрачной.

Если не уверены — оставьте рекомендуемое значение.

---

## Гамма маски

```text
1.0 = без изменения
```

Используйте только для тонкой коррекции перехода.

---

## Сдвиг края маски, px

Это реальное расширение или сжатие контура **в пикселях итогового полноразмерного файла**.

```text
+ значение  → расширить объект
- значение  → сжать объект
0           → не менять край
```

На 30–60 Мп фотографии изменение в `2–5 px` может быть почти незаметно.

Для проверки работы параметра попробуйте сначала заметную разницу:

```text
+30 px
```

и затем:

```text
-30 px
```

Если оба результата перезаписаны, разница должна быть очевидной.

После этого можно подобрать более аккуратное значение.

---

## Размытие края

Дополнительное смягчение маски.

Для современных моделей чаще всего лучше оставить:

```text
0
```

Слишком большое размытие может дать неестественный мягкий ореол.

---

# Экспериментальное уточнение края

Опция:

**«Экспериментально уточнять край по исходному изображению»**

пытается дополнительно привязать границу маски к деталям исходной фотографии.

Она не заменяет модель и работает уже после основного удаления фона.

По умолчанию функция выключена.

Её стоит включать только если обычная маска систематически выглядит слишком грубой.

На некоторых фотографиях уточнение может, наоборот, сильнее подхватить текстуру фона — поэтому лучше сравнивать результат на нескольких кадрах.

Параметр **«Макс. размер уточнения»** ограничивает расход RAM на больших фотографиях.

# Производительность и память

## NVIDIA GPU

На компьютере с NVIDIA рекомендуемый вариант:

```text
Устройство:                    auto
FP16:                          включено
Безопасно ограничивать GPU:    включено
```

В режиме `auto` программа использует CUDA, если установленная среда PyTorch её видит.

В журнале при запуске обработки должна появляться строка вида:

```text
устройство: cuda
```

Если написано `cpu`, смотрите раздел «Если программа работает на CPU вместо NVIDIA» ниже.

---

## Кадров за один GPU-проход

Это **не количество копий модели**.

Программа использует один экземпляр модели и по возможности передаёт ему несколько фотографий одним пакетом.

При включённой безопасной настройке размер пакета автоматически ограничивается для тяжёлых моделей.

Например, для BiRefNet HR обычно используется один кадр за проход.

Если видеопамяти всё же не хватает, программа пытается разбить пакет на меньшие части.

---

## Потоки чтения файлов

Это безопасный способ ускорения.

Пока GPU считает текущий файл, CPU может заранее читать следующие изображения.

Рекомендуемая отправная точка:

```text
2 потока
```

На быстром SSD можно попробовать:

```text
3–4 потока
```

Эти потоки не создают дополнительные копии модели на видеокарте.

---

## Буфер предзагрузки

Определяет, сколько следующих фотографий может заранее находиться в RAM.

Для больших файлов обычно достаточно:

```text
3
```

Больший буфер не обязательно ускоряет работу, но увеличивает расход оперативной памяти.

---

# Прогресс и отмена

Во время работы программа показывает:

- текущий этап;
- имя файла;
- общий процент;
- итоговое количество обработанных, пропущенных и ошибочных файлов.

Кнопка **«Отмена»** останавливает обработку после завершения текущего GPU-прохода.

Это сделано специально, чтобы не обрывать вычисление и запись файла посередине операции.

Уже полностью сохранённые результаты при отмене остаются на месте.

---

# Безопасность исходных файлов

Программа **не изменяет исходные фотографии**.

Она не записывает маску обратно в исходный JPEG/TIFF и не заменяет исходник прозрачной версией.

Результат всегда создаётся отдельно.

Если исходный PNG/TIFF уже содержит прозрачность, новая маска объединяется с существующим alpha-каналом — ранее прозрачные области не становятся снова непрозрачными.

---

# Безопасная запись результатов

Готовый файл сначала записывается во временный файл:

```text
имя_файла.ext.tmp
```

После успешной проверки временный файл переименовывается в итоговый.

Это уменьшает риск того, что незавершённая запись будет выглядеть как нормальный готовый файл.

Для TIFF дополнительно проверяется структура RGBA-файла перед публикацией результата.

Старые нулевые `.tmp` перед новой попыткой записи удаляются.

---

# Запуск из Total Commander

Программа поддерживает передачу списка файлов и папок через командную строку.

Для кнопки Total Commander можно использовать:

**Команда:**

```text
F:\background_remover_ai\run.bat
```

**Параметры:**

```text
%P%S
```

Не заключайте всю конструкцию `%P%S` в одну дополнительную пару кавычек — Total Commander сам корректно передаёт отдельные имена с пробелами.

Можно выделить:

- один файл;
- несколько файлов;
- папку;
- несколько папок;
- смесь файлов и папок.

Например программа может получить:

```text
D:\Photo\1A\IMG_0001.jpg
D:\Photo\1A\IMG_0002.jpg
D:\Photo\2B\
```

### Автоматическая папка результата при запуске из Total Commander

Если источники пришли через командную строку, программа **не использует старую папку результата от предыдущего задания**.

Она автоматически предлагает:

```text
Background Removed
```

рядом с текущими исходниками.

Если файлы находятся в разных папках, используется их общий родительский каталог.

Если папка результата передана явно через `--output`, автоматический выбор её не заменяет.

### 32-битный Total Commander

32-битный Total Commander можно использовать.

`run.bat` запускает 64-битный Python из локального `runtime\venv`, поэтому разрядность Total Commander не заставляет сам AI работать в 32-битном режиме.

---

# Запуск из командной строки

Один файл:

```bat
run.bat "D:\Photos\IMG_0001.jpg"
```

Папка:

```bat
run.bat "D:\Photos\Shoot"
```

Несколько файлов / папок:

```bat
run.bat "D:\Photos\1A" "D:\Photos\2B" "D:\Photos\special.jpg"
```

Можно сразу указать папку результата:

```bat
run.bat "D:\Photos\Shoot" --output "D:\Result"
```

# Какие настройки программа запоминает

Рабочие настройки сохраняются в:

```text
config\ui_state.json
```

Программа запоминает, в частности:

- выбранную модель;
- выходной режим;
- PNG или TIFF;
- профиль края;
- пороги и гамму маски;
- сдвиг и размытие края;
- guided refinement;
- работу с подпапками;
- сохранение структуры;
- перезапись готовых файлов;
- перенос метаданных;
- CPU/GPU;
- FP16;
- размер GPU-пакета;
- потоки и буфер предзагрузки;
- суффиксы `_cutout` и `_mask`;
- последнюю папку результата.

Исходный список фотографий как постоянное задание не сохраняется.

При запуске из Total Commander новая входная выборка автоматически получает актуальную предлагаемую папку `Background Removed`.

Кнопка **«Вернуть рекомендуемые значения»** возвращает основные параметры обработки к значениям по умолчанию.

# Если что-то пошло не так

## Программа работает на CPU вместо NVIDIA

На экране / в журнале видно:

```text
устройство: cpu
```

хотя в компьютере есть NVIDIA.

Сначала снова запустите:

```text
install.bat
```

Установщик проверяет CUDA уже из 64-битного локального Python и при необходимости заменяет CPU-сборку PyTorch на CUDA-сборку.

После успешной установки CUDA self-test должен пройти без ошибки.

---

## BRIA не запускается

Запустите:

```text
setup_bria.bat
```

Проверьте, что:

- выполнен вход в Hugging Face;
- условия RMBG-2.0 приняты;
- используется Read token.

---

## На волосах остался фон

Попробуйте в таком порядке:

1. **Естественный край**;
2. другую модель;
3. BiRefNet HR Matting;
4. только затем экспериментальное уточнение края;
5. после этого — ручную настройку порогов.

Не начинайте сразу с сильного сжатия маски — оно может убрать и волосы вместе с фоном.

---

## Волосы или прозрачная ткань пропадают

Вернитесь к:

```text
Естественный край
```

или:

```text
Без дополнительной обработки
```

Если проблема остаётся — сравните другую модель.

---

## Изменение края «не работает»

Проверьте два момента.

### 1. Разрешена ли перезапись

Если старый `_cutout` уже существует, а опция:

```text
Перезаписывать готовые файлы
```

выключена, новый параметр к нему не применяется.

### 2. Достаточно ли велик тестовый сдвиг

На очень большой фотографии `2–5 px` могут быть почти незаметны.

Для проверки попробуйте сначала:

```text
+30
```

и:

```text
-30
```

после чего уменьшайте значение до нужного.

---

## Недостаточно VRAM

Сначала:

1. оставьте **«Безопасно ограничивать GPU-пакет»** включённым;
2. поставьте **«Кадров за один GPU-проход» = 1**;
3. закройте другие приложения, активно использующие видеокарту.

Потоки чтения файлов обычно уменьшать не требуется — они расходуют прежде всего RAM, а не создают копии AI-модели в VRAM.

---

## TIFF не сохраняется

Текущий TIFF-export не использует старую проблемную ветку Pillow/libtiff для основного RGBA-файла.

Если всё равно возникает проблема:

1. проверьте `background_remover_ai.log`;
2. проверьте `background_remover_ai_crash.log`;
3. посмотрите, остаётся ли рядом `.tif.tmp`;
4. попробуйте тот же кадр сохранить как PNG — это помогает понять, проблема в модели или именно в TIFF-export.

Нулевой старый `.tmp` при следующей попытке должен автоматически удаляться.

---

## Программа ничего не обрабатывает после изменения настроек

Если все результаты уже существуют и перезапись выключена, программа не загружает тяжёлую модель зря.

Она сообщает, что файлы уже готовы.

Чтобы применить новые настройки:

- включите перезапись;
- или выберите новую папку результата.

---

## Первый запуск долго стоит на «Загрузка модели»

Это нормально, если эта модель ещё не скачивалась.

После загрузки она останется в локальном кэше и следующие запуски будут быстрее.

---

# Обновление программы

Самый безопасный способ проверить новую версию:

1. распаковать её в новую папку;
2. запустить `install.bat`;
3. проверить несколько фотографий;
4. только затем переходить на неё окончательно.

Папка:

```text
runtime\venv
```

не считается переносимым Python-окружением между разными компьютерами. На новом компьютере лучше заново выполнить `install.bat`.

Модели находятся отдельно в `runtime\huggingface` и при необходимости могут быть скачаны заново.
